Unit 4–5 · Further Chemistry

4.1 Kinetics · Topic 11

  • rate equations、orders、rate constants 与 half-life
  • initial-rate、continuous monitoring、titration、colorimetry 与 gas-volume methods
  • rate-determining steps、mechanisms、SN1/SN2 与 acid-catalysed iodination of propanone
  • Arrhenius equation、activation energy、heterogeneous catalysis 与 core practicals

4.2 Entropy · Topic 12A

  • entropy、disorder、random dispersal of particles and energy quanta
  • entropy changes in changes of state、dissolving、gas formation and reactions
  • \(\Delta S_{\mathrm{system}}\)、\(\Delta S_{\mathrm{surroundings}}\)、\(\Delta S_{\mathrm{total}}\) 与 feasibility
  • Gibbs free energy extension、temperature threshold、thermodynamic stability 与 kinetic stability

4.3 Energetics · Topic 12B

  • lattice energy、atomisation enthalpy、electron affinity 与 Born-Haber cycles
  • polarisation、covalent character、ionic charge 与 ionic radius
  • enthalpy of solution、enthalpy of hydration 与 energy cycles
  • solubility predictions using entropy、enthalpy and temperature

4.4 Chemical Equilibria · Topic 13

  • \(K_c\) expressions、equilibrium concentrations 与 ICE tables
  • \(K_p\) expressions、partial pressure、mole fraction 与 units
  • temperature、pressure、concentration、catalyst 对 equilibrium 的影响
  • entropy、\(\Delta S_{\mathrm{total}}\)、\(K\) 与 equilibrium position

4.5 Acid-base Equilibria · Topic 14

  • Brønsted-Lowry acids / bases、conjugate pairs 与 proton transfer
  • pH、\(K_a\)、p\(K_a\)、\(K_w\)、p\(K_w\) 与 strong / weak acids
  • pH calculations、titration curves、indicator selection 与 equivalence point
  • buffer action、Henderson-Hasselbalch equation、blood / food buffers 与 Core Practical 11

4.6 Organic Chemistry Chirality · Topic 15A

  • chiral centres、enantiomers 与 non-superimposable mirror images
  • optical activity、plane-polarised light、racemates 与 enantiopure compounds
  • optical activity as evidence for SN1 / SN2 mechanisms and inversion of configuration
  • nucleophilic addition to planar carbonyl compounds and possible racemic products

4.7 Organic Chemistry Carbonyls · Topic 15B

  • aldehydes、ketones、carbonyl nomenclature 与 structural / displayed / skeletal formulae
  • carbonyl polarity、intermolecular forces、boiling temperatures 与 water solubility
  • oxidation、reduction、Tollens’、Fehling’s / Benedict’s、2,4-DNPH 与 iodoform tests
  • HCN nucleophilic addition、hydroxynitriles、optical activity 与 carbonyl identification

4.8 Organic Chemistry Carboxylic Acids · Topic 15C / 15D

  • carboxylic acids、acyl chlorides、esters 的 nomenclature 与 displayed / skeletal formulae
  • preparation、weak-acid behaviour、hydrogen bonding、solubility 与 key reactions
  • acyl chloride hydrolysis、esterification、amide formation 与 nucleophilic addition-elimination
  • acid / alkaline ester hydrolysis、PET / Terylene 与 polyester condensation polymerisation

4.9 Organic Analytical Techniques · Topic 15E

  • high-resolution mass spectrometry 与 accurate molecular formula calculation
  • \(^{13}\)C NMR、low / high-resolution \(^{1}\)H NMR、chemical shifts、integration 与 splitting
  • TLC、mobile / stationary phases、\(R_f\) values 与 chromatography workflow
  • HPLC、GC、retention times、GC-MS / HPLC-MS 与 forensic applications

5.1 Redox Equilibria · Topic 16

  • oxidation / reduction、standard electrode potentials、SHE 与 electrochemical series
  • half-cells、salt bridges、cell diagrams、\(E^\circ_{\mathrm{cell}}\) 与 thermodynamic feasibility
  • disproportionation、entropy / \(\ln K\) relationships、kinetic limitations 与 fuel cells
  • manganate(VII)-iron(II)、iodine-thiosulfate redox titrations 与 uncertainty analysis

5.2 Transition Metals and their Chemistry · Topic 17

  • d-block configurations、variable oxidation numbers、complex ions 与 ligand bonding
  • colour、d-orbital splitting、coordination geometry、cisplatin 与 haemoglobin
  • vanadium / chromium redox chemistry、hydroxide / ammonia reactions 与 ligand exchange
  • heterogeneous / homogeneous catalysis、autocatalysis 与 Core Practical 14

5.4 Organic Chemistry Arenes · Topic 18

  • benzene structure、delocalised \(\pi\) system、aromatic stability 与 evidence
  • hydrogenation enthalpy、X-ray bond lengths、IR data 与 bromination resistance
  • halogenation、nitration、sulfonation、Friedel-Crafts substitution mechanisms
  • phenol bromination、2,4,6-tribromophenol、common uses 与 safety context

5.5 Organic Chemistry Nitrogen Compounds · Topic 19

  • amines、amides、amino acids 的 nomenclature、basicity、reactions 与 preparation
  • phenylamine、diazotization、azo dyes、amide formation 与 copper(II) complexes
  • polyamides、proteins、peptide bonds、poly(propenamide) 与 poly(ethenol)
  • zwitterions、isoelectric point、optical activity 与 Core Practical 15 unknown analysis

5.6 Organic Synthesis · Topic 20

  • combustion analysis、empirical / molecular formula、IR、MS 与 NMR structure deduction
  • reaction schemes、functional-group interconversion、Grignard reagents 与 carbon-chain extension
  • reflux、distillation、steam distillation、washing、extraction 与 recrystallisation
  • aspirin Core Practical 16、melting / boiling temperature、purity 与 risk control
